# Birko.Data.Migrations.SQL

SQL database migration provider for the Birko Framework.

## Features

- Up/Down migrations for SQL databases
- Transaction support per migration
- Migration history tracking table
- Supports MSSQL, PostgreSQL, MySQL, SQLite, TimescaleDB

## Installation

```bash
dotnet add package Birko.Data.Migrations.SQL
```

## Dependencies

- Birko.Data
- Birko.Data.Migrations
- Birko.Data.SQL
