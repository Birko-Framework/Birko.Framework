# Birko.Data.Migrations.TimescaleDB

TimescaleDB migration provider for the Birko Framework.

## Features

- Extends SQL migrations with hypertable support
- Compression policy migrations
- Continuous aggregate management
- Retention policy migrations

## Installation

```bash
dotnet add package Birko.Data.Migrations.TimescaleDB
```

## Dependencies

- Birko.Data
- Birko.Data.Migrations
- Birko.Data.Migrations.SQL
- Birko.Data.TimescaleDB
