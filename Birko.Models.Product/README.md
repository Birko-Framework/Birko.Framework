# Birko.Models.Product

Product domain models for the Birko Framework.

## Features

- Product entity with variants, images, and pricing
- Product ViewModels and list ViewModels
- Product filters (by category, etc.)

## Installation

```bash
dotnet add package Birko.Models.Product
```

## Dependencies

- Birko.Models

## API Reference

### Models (namespace: Birko.Models.Product)

- **Product** - Core product entity
- **ProductVariant** - Product variant
- **ProductImage** - Product image
- **ProductPrice** - Product pricing

### ViewModels (namespace: Birko.Models.Product.ViewModels)

- **ProductViewModel** / **ProductListViewModel**

### Filters (namespace: Birko.Models.Product.Filters)

- **ProductFilter** / **ProductCategoryFilter**
