# Birko.Data.CosmosDB.ViewModel

ViewModel repositories for Azure Cosmos DB with bulk operations support.

## Features

- ViewModel-to-Model mapping via `ILoadable<T>`
- Bulk CRUD operations
- Supports wrapped stores (e.g., tenant wrappers)

## Dependencies

- Birko.Data.Core
- Birko.Data.Stores
- Birko.Data.Repositories
- Birko.Data.CosmosDB
- Microsoft.Azure.Cosmos
