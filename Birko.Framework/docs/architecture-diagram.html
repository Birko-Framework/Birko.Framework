Birko.Framework Architecture Diagram

Architecture Overview: This diagram illustrates the layered architecture of Birko.Framework, showing dependency flow from foundations (zero dependencies) through core infrastructure, data access layers, to AI/communication components. Arrows indicate dependency direction (bottom → top).

How to Use These Diagrams

Option 1: View in Browser (Mermaid.js)

Simply open this HTML file in any modern web browser. The diagram above is rendered using Mermaid.js.

Option 2: Online Mermaid Editor

Visit https://mermaid.live and paste the contents of architecture-diagram.mermaid.

Option 3: PlantUML

Use PlantUML to render architecture-diagram.puml:

  • Online: http://www.plantuml.com/plantuml
  • VS Code: Install the "PlantUML" extension
  • Command line: plantuml architecture-diagram.puml

Option 4: Integrated Development Environments

  • VS Code: Install "Markdown Preview Mermaid Support" extension for Mermaid in MD files
  • IntelliJ IDEA: Built-in PlantUML support
  • GitHub/GitLab: Mermaid diagrams render automatically in Markdown files

Architecture Key Points

  • Template Method Pattern: Store hierarchy uses lazy-init with protected *Core methods
  • Dependency Flow: Bottom-up - foundations have zero dependencies, upper layers depend on lower
  • Clean Separation: Models are independent of data access, AI is isolated from core data layer
  • Reference Implementations: ElasticSearch (async/bulk) and JSON (file-based) provide implementation patterns
Tip: You can edit the .mermaid or .puml files directly to customize the diagram for your needs. The HTML file uses Mermaid.js for immediate browser rendering.
