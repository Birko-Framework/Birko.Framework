# Birko.Data.Views.Tests

Unit tests for the Birko.Data.Views project.

## Test Framework

- **xUnit** 2.9.3
- **FluentAssertions** 7.0.0
- **.NET 10.0**

## Test Coverage

- **ViewDefinitionBuilderTests** — Fluent view definition API (columns, joins, filters, ordering, grouping)
- **ViewMapRegistryTests** — Registry registration, lookup, and validation
- **ViewResultTests** — View result construction and properties

## Running Tests

```bash
dotnet test Birko.Data.Views.Tests.csproj
```
