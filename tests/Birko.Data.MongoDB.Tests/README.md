# Birko.Data.MongoDB.Tests

Unit tests for MongoDB data layer in the Birko Framework.

## Test Coverage

- **AggregationPipelineBuilderTests** - Aggregation pipeline builder construction and stage composition
- **ChangeStreamOptionsTests** - Change stream options configuration and filtering

## Test Framework

- xUnit 2.9.3
- FluentAssertions 7.0.0
- Moq 4.20.72
- .NET 10.0

## Running Tests

```bash
dotnet test Birko.Data.MongoDB.Tests.csproj
```
