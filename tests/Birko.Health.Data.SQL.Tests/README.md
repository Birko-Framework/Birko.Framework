# Birko.Health.Data.SQL.Tests

Test suite for [Birko.Health.Data.SQL](../../Framework/Birko.Health.Data.SQL/README.md).

## Test framework

xUnit + FluentAssertions.

## Running tests

```
dotnet test --nologo
```

No server required — the suite runs against on-disk SQLite.
