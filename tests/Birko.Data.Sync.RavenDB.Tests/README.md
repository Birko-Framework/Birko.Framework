# Birko.Data.Sync.RavenDB.Tests

Unit tests for the RavenDB sync-knowledge store.

## Running Tests

```bash
dotnet test
```

Store query/delete behavior needs a live RavenDB server and is not covered here. Building this
project compile-verifies the CR-C19 / CR-C20 store fixes.
