# Birko.Models.Category

Category domain models with hierarchical tree support for the Birko Framework.

## Features

- Category entity with tree hierarchy
- Category ViewModels with tree representation
- Category filters

## Installation

```bash
dotnet add package Birko.Models.Category
```

## Dependencies

- Birko.Models
- Birko.Structures (tree operations)

## API Reference

### Models (namespace: Birko.Models.Category)

- **Category** - Category entity
- **CategoryTree** - Hierarchical category tree

### ViewModels (namespace: Birko.Models.Category.ViewModels)

- **CategoryViewModel** / **CategoryTreeViewModel**

### Filters (namespace: Birko.Models.Category.Filters)

- **CategoryFilter**
