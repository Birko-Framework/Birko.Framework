# Birko.Models.SEO

SEO metadata models for the Birko Framework.

## Features

- SEO metadata entity (Open Graph, canonical URLs, robots meta)
- URL alias/redirect management
- Sitemap item definitions
- SEO filters

## Installation

```bash
dotnet add package Birko.Models.SEO
```

## Dependencies

- Birko.Models

## API Reference

### Models (namespace: Birko.Models.SEO)

- **SEOMetadata** - SEO metadata entity
- **URLAlias** - URL redirect/alias
- **SitemapItem** - Sitemap entry

### ViewModels (namespace: Birko.Models.SEO.ViewModels)

- **SEOMetadataViewModel**

### Filters (namespace: Birko.Models.SEO.Filters)

- **SEOFilter**
